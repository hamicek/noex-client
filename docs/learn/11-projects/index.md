# Part 11: Projects

Apply everything you've learned in complete, real-world projects.

## Chapters

### [11.1 Todo App](./01-todo-app.md)

Build a real-time todo application:
- CRUD operations for todos
- Reactive subscriptions for live updates across clients
- Proper cleanup and error handling

### [11.2 Realtime Dashboard](./02-realtime-dashboard.md)

Build a monitoring dashboard with live data:
- Reactive queries with aggregations
- Authentication and role-based access
- Multi-client synchronization

### [11.3 Chat Application](./03-chat-application.md)

Build a chat system combining multiple SDK features:
- Rules engine for message routing and notifications
- Subscriptions for live message delivery
- Reconnect recovery for seamless experience
- Transactions for consistent state updates

## What You'll Learn

By the end of this section, you'll have built three complete applications that demonstrate:
- How to combine store, subscriptions, rules, and auth in practice
- Patterns for production-quality real-time applications
- End-to-end architecture from client to server
