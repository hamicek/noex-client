# Část 11: Projekty

Aplikujte vše, co jste se naučili, v kompletních reálných projektech.

## Kapitoly

### [11.1 Todo aplikace](./01-todo-aplikace.md)

Vytvořte real-time todo aplikaci:
- CRUD operace pro todo položky
- Reaktivní odběry pro živé aktualizace napříč klienty
- Správný cleanup a zpracování chyb

### [11.2 Dashboard v reálném čase](./02-dashboard-v-realnem-case.md)

Vytvořte monitorovací dashboard s živými daty:
- Reaktivní dotazy s agregacemi
- Autentizace a přístup podle rolí
- Synchronizace více klientů

### [11.3 Chatovací aplikace](./03-chatovaci-aplikace.md)

Vytvořte chatovací systém kombinující více funkcí SDK:
- Pravidlový engine pro směrování zpráv a notifikace
- Subscriptions pro živé doručování zpráv
- Reconnect recovery pro bezproblémový zážitek
- Transakce pro konzistentní aktualizace stavu

## Co se naučíte

Na konci této sekce budete mít tři hotové aplikace, které demonstrují:
- Jak kombinovat store, subscriptions, rules a auth v praxi
- Vzory pro produkčně kvalitní real-time aplikace
- End-to-end architekturu od klienta po server
